3. O(N log N) Merge Sort on Linked List

Algorithm: Divide-and-conquer Merge Sort implemented on singly linked lists via pointer splitting (slow/fast pointers).
Time Complexity: O(N log N) Guaranteed, O(log N) Call stack space.
Purpose: Powers the Biller Dashboard's analytics sorting by total order value (Low to High and High to Low).

void split_list(Order* source, Order** frontRef, Order** backRef);

4. O(log N) Binary Search on Order Array

Algorithm: Classic iterative binary search operating on contiguous arrays of order references sorted by numeric ID.
Time Complexity: O(log N) Time, O(1) Auxiliary space.
Purpose: Sub-millisecond lookup when searching through indexed archives by order identifier.

int binary_search_order_by_id(Order* orders[], int low, int high, int target_id);

How to Compile and Run the C Module

The C source code is located in the c_core/ folder with full header files, implementation, unit tests, and Makefile.

Compilation on Windows (MinGW / GCC)
cd c_core
gcc -Wall -Wextra -O2 -o food_court_ds_cli.exe food_court_ds.c main.c
./food_court_ds_cli.exe test
Building Shared Library (DLL / .so for ctypes)
# Windows DLL
gcc -shared -o food_court_ds.dll food_court_ds.c

# Linux / MacOS Shared Object
gcc -fPIC -shared -o libfoodcourt.so food_court_ds.c
